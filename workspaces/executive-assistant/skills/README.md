# Executive Assistant Skills

These are workspace-specific SOPs. They may call the shared department and TSOT
skills, but they must not duplicate project doctrine or voice rules.

The router is the shared EA entrypoint for both Codex and Claude. Use it before
choosing a narrower skill when the user's requested outcome is not already
explicitly scoped.

| Skill | Purpose | External write authority |
|---|---|---|
| `inquiry-router` | Classify any inquiry and coordinate bounded department work | None |
| `daily-brief` | Prepare daily and weekly summaries | None |
| `meeting-prep` | Prepare for a selected calendar event | None |
| `referral-triage` | Classify inbound opportunities and draft responses | None |
